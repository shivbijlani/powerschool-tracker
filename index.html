⚡ Super Quick Install (Windows)

Starting from scratch? Copy this ONE command!

Open PowerShell (search for "PowerShell" in Start menu, right-click, "Run as Administrator") and paste:

winget install Microsoft.VisualStudioCode Git.Git OpenJS.NodeJS

This installs:

  • VS Code - Code editor with Copilot
  • Git - Downloads the project
  • Node.js - Runs the browser automation (includes npm)

After install completes, close and reopen PowerShell, then skip to Step 3 below!

Alternative: Use Ninite for VS Code + Git, then install Node.js separately:

Install VS Code + Git with Ninite Then Install Node.js

Ninite doesn't include Node.js, so you'll need to install it separately.

🚀 Complete Setup Guide

Total time: 5-10 minutes

1

Install VS Code

Visual Studio Code is a free code editor from Microsoft that includes GitHub Copilot.

Windows Quick Install:

winget install Microsoft.VisualStudioCode

Or download manually:

Download VS Code

Choose Windows, Mac, or Linux. Run the installer and follow the prompts.

2

Install Git & Node.js

Git downloads code from GitHub. Node.js runs the automation tool (includes npm for packages).

Windows Quick Install:

winget install Git.Git OpenJS.NodeJS

After install, close and reopen any open terminals!

Or download manually:

Download Git Download Node.js

Run the installers. Accept all defaults - just keep clicking "Next". Both Git and Node.js are required!

3

Get GitHub Copilot

GitHub Copilot is the AI that automates everything. First 30 days free!

1. Open VS Code
2. Click the Extensions icon (or press Ctrl+Shift+X)
3. Search for GitHub Copilot
4. Click Install
5. Sign in with your GitHub account (create one if needed)

Learn About Copilot
4

Clone This Project

Download the PowerSchool Tracker code to your computer:

1. Open VS Code
2. Press Ctrl+Shift+P (or Cmd+Shift+P on Mac)
3. Type: Git: Clone
4. Paste this URL:

https://github.com/shivbijlani/powerschool-tracker.git

5. Choose a folder to save it
6. Click "Open" when prompted

5

Start Tracking!

This is the magic part - one simple command does everything:

1. Press Ctrl+Alt+I (or Cmd+Alt+I on Mac) to open Copilot Chat
2. Type or paste this:

Help me track my kids' school using PowerSchool

3. Hit Enter and follow Copilot's instructions!

✅ That's it! Copilot will:
  • Install needed packages
  • Open your PowerSchool portal in a browser
  • Detect all your students
  • Create folders and snapshots for each one

💬 What You Can Ask Copilot

Once set up, you can say things like:

  • "Create new snapshots" - Update all grades
  • "What are Alex's current grades?" - Check one student
  • "Has Morgan's math grade improved?" - Compare over time
  • "Show me missing assignments" - See what's due
  • "Check attendance" - Review absences and tardies

🏫 Compatible School Districts

This tool works with any school district that uses PowerSchool. If your school's portal URL looks like:

ps.yourdistrict.org
powerschool.yourdistrict.org

...then it will work! Just tell Copilot your district's URL when it asks.

⚠️ Note: This is specifically for PowerSchool portals. Other systems (Skyward, Infinite Campus, etc.) are not currently supported.

🔒 Privacy & Security

Your data never leaves your computer.

  • All student data is stored locally in folders on your machine
  • Browser automation happens on your computer using your saved passwords
  • No cloud uploads, no data sharing, no tracking
  • Student folders are automatically excluded from git so they're never uploaded

❓ Troubleshooting

Copilot doesn't respond

Make sure you're signed in to GitHub Copilot. Look for the Copilot icon in the bottom-right of VS Code - it should show a checkmark.

npm command not found?

Node.js might not be installed or you need to restart VS Code after installing it. Close VS Code completely and reopen it, or install Node.js from nodejs.org.

Don't have PowerShell as Administrator?

No problem! Just download the installers manually from the links in each step. Or use the Ninite link at the top.

winget not found?

You might have an older Windows version. Use the manual download links instead, or try Ninite.

Browser doesn't open

Try running npm install in VS Code's terminal first. This installs the browser automation tool.

Can't log in to PowerSchool

Make sure you're using your parent/guardian account, not a student account.

Check out the full documentation on GitHub.
