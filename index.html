🚀 Quick Setup for Windows

Complete automated installation script — installs tools, downloads project, creates desktop shortcut

⚠️ Why Administrator? Installing software (VS Code, Git, Node.js) requires admin permissions on Windows. This is standard for any software installation.

Step 1: Open PowerShell as Administrator

Right-click Start menu → "Windows PowerShell (Admin)" or "Terminal (Admin)"

Step 2: Copy the setup script

# Install VS Code, Git, Node.js and fix PowerShell Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force winget install Microsoft.VisualStudioCode Git.Git OpenJS.NodeJS --accept-package-agreements --accept-source-agreements # Refresh PATH so git works $env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User") # Clone the project to your user folder cd $env:USERPROFILE git clone https://github.com/shivbijlani/powerschool-tracker.git # Create desktop shortcut to open project in VS Code $WshShell = New-Object -comObject WScript.Shell $DesktopPath = [Environment]::GetFolderPath("Desktop") $Shortcut = $WshShell.CreateShortcut("$DesktopPath\PowerSchool Tracker.lnk") $Shortcut.TargetPath = "$env:LOCALAPPDATA\Programs\Microsoft VS Code\Code.exe" $Shortcut.Arguments = "$env:USERPROFILE\powerschool-tracker" $Shortcut.WorkingDirectory = "$env:USERPROFILE\powerschool-tracker" $Shortcut.Save() Write-Host "`n✅ DONE! Double-click 'PowerSchool Tracker' on your desktop to get started!" -ForegroundColor Green

Step 3: Paste into PowerShell and press Enter

Right-click in PowerShell to paste, then hit Enter. Wait 3-5 minutes.

Step 4: Look for "PowerSchool Tracker" on your desktop

Double-click it to open VS Code with the project loaded!

✅ What this script does:
  • Enables PowerShell scripts (safe, user-level only)
  • Installs Microsoft VS Code, Git, and Node.js using official installers
  • Downloads this project to C:\Users\YourName\powerschool-tracker
  • Creates a desktop shortcut for easy access

🔒 Safe & Open Source: All code is visible above and on GitHub. This uses Microsoft's official package manager (winget) to install legitimate software.

🚀 Quick Setup for Mac

Complete automated installation script — installs tools, downloads project, opens in VS Code

Step 1: Open Terminal

Press Cmd+Space, type "Terminal", press Enter

Step 2: Copy the setup script

#!/bin/bash # Install Homebrew if not installed if ! command -v brew &> /dev/null; then /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" fi # Install VS Code, Git, Node.js brew install --cask visual-studio-code brew install git node # Clone the project cd ~ git clone https://github.com/shivbijlani/powerschool-tracker.git # Open in VS Code code ~/powerschool-tracker echo "✅ DONE! VS Code should open with the project loaded."

Step 3: Paste into Terminal and press Enter

Cmd+V to paste, then hit Enter. Wait 3-5 minutes. You may need to enter your password.

Step 4: VS Code will open automatically

The project will be loaded and ready to use!

✅ What this script does:
  • Installs Homebrew (Mac package manager) if needed
  • Installs VS Code, Git, and Node.js
  • Downloads this project to ~/powerschool-tracker
  • Opens VS Code with the project loaded

🔒 Safe & Open Source: All code is visible above and on GitHub. This uses Homebrew, the standard Mac package manager.

Once set up, you can say things like:

  • "What are Alex's current grades?" - Check one student

🏫 Compatible School Districts

This tool works with any school district that uses PowerSchool. If your school's portal URL looks like:

ps.yourdistrict.org
powerschool.yourdistrict.org

...then it will work! Just tell Copilot your district's URL when it asks.

⚠️ Note: This is specifically for PowerSchool portals. Other systems (Skyward, Infinite Campus, etc.) are not currently supported.

🔒 Privacy & Security

Your data never leaves your computer.

  • All student data is stored locally in folders on your machine
  • Browser automation happens on your computer using your saved passwords
  • No cloud uploads, no data sharing, no tracking
  • Student folders are automatically excluded from git so they're never uploaded

❓ Troubleshooting

Copilot doesn't respond

Make sure you're signed in to GitHub Copilot. Look for the Copilot icon in the bottom-right of VS Code - it should show a checkmark.

npm.ps1 cannot be loaded / running scripts is disabled?

This is a PowerShell security setting. Open PowerShell and run:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Type Y and press Enter to confirm. This allows npm to run and is safe for your user account.

npm command not found?

Node.js might not be installed or you need to restart VS Code after installing it. Close VS Code completely and reopen it, or install Node.js from nodejs.org.

Don't have PowerShell as Administrator?

No problem! Just download the installers manually from the links in each step. Or use the Ninite link at the top.

winget not found?

You might have an older Windows version. Use the manual download links instead, or try Ninite.

Browser doesn't open

Try running npm install in VS Code's terminal first. This installs the browser automation tool.

Can't log in to PowerSchool

Make sure you're using your parent/guardian account, not a student account.
